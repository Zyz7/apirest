# ApiRestC#

<img width="1916" height="953" alt="Screenshot124725" src="https://github.com/user-attachments/assets/2eb2f86e-08f5-403e-892d-ff5ca0c0eb96" />


A token is created at the time of login and unblock all endpoints to create, get, modify or delete products, categories, users, suppliers and password modifications.
It is an application that starts with registration and login as well as password recovery. When you log in, products assigned to categories and created by different users are displayed. 
All endpoint get are unlocked and so is the one used to create users.

## languages used

- c#
- sqlite
- swagger
